# Select a UI design

1. Read the affected screen and nearby primitives in `components/ui/`. Use the mobile layout and Traditional Chinese copy as constraints.
2. Present two or three distinct options with a preview where practical. Compare the touch interaction, hierarchy, accessibility, and any changes to state or navigation.
3. Ask the owner to select an option or request revisions before implementing the issue.
4. Record the selection, preview reference, and reason in the issue. Add an acceptance criterion that someone can verify at mobile width.
